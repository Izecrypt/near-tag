honesty limits

  • oracle. one Ed25519 attestor signs each daily epoch, bound to this contract and chain ID. the contract enforces caps, dedupe, quorum, pot limits and the holding ceiling. validator votes exist to discipline the attestor.
  • demo status. this hackathon demo runs on NEAR testnet with a labeled synthetic epoch. live mode is the same code, same rules, mainnet token via meme.cooking.
  • sybil limits. a wallet's first attested X link is permanent. fingerprints can only ever be paid once.
  • buyback. a NEAR pot is reserved for market buybacks. refill() stays disabled until the Ref testnet pool path is verified. no buyback is claimed as executed.
  • the token itself. at launch TAG is a factory-standard NEP-141 from meme.cooking: no mint, no fee inside the token, no admin powers over it, ever. the economy lives in this separate mechanics contract.
